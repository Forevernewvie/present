Present(com.presentcare.app) 이용자는 언제든지 앱 내부에서 직접 계정을 즉시 삭제(회원 탈퇴)하거나, 앱을 이미 삭제한 경우 웹(이메일)을 통해 계정 및 모든 연관 데이터의 영구 삭제를 요청할 수 있습니다.

방법 1. 앱 내에서 직접 즉시 삭제하기 (권장)

  1. 스마트폰에서 Present 앱을 실행합니다.
  2. 메인 화면 우측 상단의 [설정(⚙️ 아이콘)] 버튼을 터치하여 [앱 설정 및 정보] 창을 엽니다.
  3. 창 하단 우측의 빨간색 [회원 탈퇴] 버튼을 터치합니다.
  4. 확인 안내창에서 [탈퇴 및 데이터 삭제] 버튼을 누르면 별도의 대기 기간 없이 즉시 계정과 모든 대화 데이터가 영구 삭제됩니다.

방법 2. 앱을 이미 삭제한 경우 웹(이메일)으로 삭제 요청하기
